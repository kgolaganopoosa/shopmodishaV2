Supabase Database Configuration

How it works: Paste your Supabase Project URL and Public Anon Key below to connect live to your Supabase PostgreSQL database. Run the SQL script below in your Supabase SQL Editor to create the tables and seed the admin password (#PetalChain_25).
Required Supabase SQL Schema 
-- 1. Admin Settings Table (Stores #PetalChain_25)
CREATE TABLE IF NOT EXISTS admin_settings (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    password TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Seed Admin Password
INSERT INTO admin_settings (password)
SELECT '#PetalChain_25'
WHERE NOT EXISTS (SELECT 1 FROM admin_settings WHERE password = '#PetalChain_25');

-- 2. Shop MODISHA Rewards Customers Table
CREATE TABLE IF NOT EXISTS rewards_customers (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    card_id TEXT UNIQUE NOT NULL,
    full_name TEXT NOT NULL,
    phone TEXT,
    pin VARCHAR(4) NOT NULL,
    lock_code VARCHAR(3) NOT NULL,
    rewards_amount NUMERIC(10, 2) NOT NULL DEFAULT 0.00,
    message TEXT DEFAULT 'Welcome to Shop MODISHA Rewards!',
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Enable Public API Access (RLS Policies for Client App)
ALTER TABLE admin_settings ENABLE ROW LEVEL SECURITY;
ALTER TABLE rewards_customers ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow read admin_settings" ON admin_settings;
CREATE POLICY "Allow read admin_settings" ON admin_settings FOR SELECT USING (true);

DROP POLICY IF EXISTS "Allow full access rewards_customers" ON rewards_customers;
CREATE POLICY "Allow full access rewards_customers" ON rewards_customers FOR ALL USING (true) WITH CHECK (true);

Privacy Policy

At Shop MODISHA, accessible through our express PWA web portal, we are committed to maintaining the trust and confidence of our customers. This Privacy Policy outlines how your personal information is handled.

1. Information We Collect

When placing an order using our web form, we require specific details necessary for completing your transaction, including your Full Name, list of shopping items, budget/cash amount, and preferred payment method. For Shop MODISHA Rewards members, we store your name, Card ID, PIN, Lock Code, and rewards balance in our secure Supabase database.

2. How Your Information Is Processed

Your order data is formatted directly on your device into a pre-structured message sent straight to our WhatsApp business line (0824598656). Rewards balances are managed strictly by authorized Shop MODISHA administrators.

3. Communication

We only use your provided contact information (WhatsApp number and provided name) to confirm order fulfillment, total prices, rewards updates, and schedule delivery to your location.

4. Data Security & Storage

WhatsApp provides end-to-end encryption for chat communications. Offline form drafts are stored strictly on your local browser cache and are never shared.
